# Fix NeuralWatt Provider Registration in OpenCode v1.14

> **For agentic workers:** REQUIRED: Use subagent-driven-development (if subagents available). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist the neuralwatt provider configuration into OpenCode's config service so the provider is discovered and its models are available.

**Architecture:** OpenCode v1.14's `config` hook discards in-place mutations to the config snapshot. The fix uses `client.config.update()` (PATCH `/config` HTTP API) to persist provider configuration with static model capabilities from `src/constants.ts`. Dynamic model fetching via the `provider.models()` hook is structurally blocked by OpenCode's initialization order (provider hooks process before config-based providers are added to the database). The `provider` hook is preserved for future compatibility.

**Tech Stack:** TypeScript, Bun, `@opencode-ai/plugin`, `@opencode-ai/sdk`

- [ ] **Step 3: Implement `configModelsFromCapabilities()` in `src/models.ts`**

Add this export after the `fetchModels` function (before the end of the file):

```typescript
export interface ConfigModelEntry {
  limit: { output: number };
  temperature: boolean;
  reasoning: boolean;
  attachment: boolean;
  tool_call: boolean;
  modalities?: { input: string[]; output: string[] };
  options?: Record<string, unknown>;
}

export function configModelsFromCapabilities(): Record<string, ConfigModelEntry> {
  const result: Record<string, ConfigModelEntry> = {};
  for (const [id, caps] of Object.entries(MODEL_CAPABILITIES)) {
    const isFast = id.endsWith('-fast');
    const hasImage = Boolean(caps.modalities?.input.includes('image' as const));
    result[id] = {
      limit: { output: caps.limit.output },
      temperature: true,
      reasoning: isFast ? false : true,
      attachment: hasImage,
      tool_call: true,
      ...(caps.modalities
        ? { modalities: caps.modalities as { input: string[]; output: string[] } }
        : {}),
      ...(caps.options ? { options: caps.options } : {}),
    };
  }
  return result;
}
```

    config: async (config) => {
      config.provider = config.provider ?? {};
      const needsUpdate = !config.provider.neuralwatt?.npm;

      // In-place mutation for backward compatibility with pre-v1.14 OpenCode
      config.provider.neuralwatt = config.provider.neuralwatt ?? {
        npm: '@ai-sdk/openai-compatible',
        name: 'NeuralWatt',
        options: {
          baseURL: BASE_URL,
        },
      };

      // Persist via client API for OpenCode v1.14+ compatibility.
      // The in-place mutation above is discarded by v1.14's immutable config service.
      if (needsUpdate) {
