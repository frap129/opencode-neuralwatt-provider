# Fix OpenCode Plugin Loading (v1 PluginModule Format)

## Problem

OpenCode's plugin loader (v1.3.8+) requires npm server plugins to declare their entrypoint explicitly via `package.json`. Our current `package.json` only has `exports["."]`, which the loader ignores — it only resolves `./server` or `./tui` from `exports`, never falling back to `exports["."]`. With no `./server` entry and no `"main"` field, the plugin is skipped during install with:

> "opencode-neuralwatt-provider@latest" does not expose plugin entrypoints in package.json

Additionally, the current `src/index.ts` exports a bare function as default. OpenCode now prefers the v1 `PluginModule` shape:

```ts
export default { id?: string, server: Plugin }
```

The legacy fallback (`getLegacyPlugins`) iterates every module export and throws `TypeError("Plugin export is not a function")` if any named export is not callable. Using the v1 format bypasses this fragile path entirely.

## Solution

### 1. Update `package.json` to declare server entrypoint

Add `exports["./server"]` pointing to the built output, and add `"main"` as a fallback. Keep `exports["."]` for consumers who import the package directly.

**File:** `package.json`

Changes:

- Add `"main": "./dist/index.js"`
- Add `"exports"["./server"]` with `"import"` and `"types"` subpaths

### 2. Update `src/index.ts` to v1 PluginModule shape

Replace the bare default function export with a `PluginModule` object. Keep the named export for internal test imports.

**File:** `src/index.ts`

Changes:

- Keep `export const NeuralWattPlugin: Plugin = async ({ client }) => { ... }`
- Replace `export default NeuralWattPlugin` with:
  ```ts
  export default {
    id: 'opencode-neuralwatt-provider',
    server: NeuralWattPlugin,
  };
  ```

### 3. Update tests to import plugin function correctly

Tests currently import `NeuralWattPlugin` as a named export. This will continue to work since we keep the named export. However, we should add a test verifying the default export shape matches `PluginModule`.

**File:** `tests/index.test.ts`

Changes:

- Add test: `it('exports v1 PluginModule shape', async () => { ... })`
  - Verify `mod.default` is an object with `id` and `server` properties
  - Verify `typeof mod.default.server === 'function'`
